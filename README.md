### O que estou construindo agora

- **Pedeli**: SaaS de gestão para restaurantes e delivery. Inclui cardápio digital, pedidos em tempo real, PDV, cozinha, estoque e financeiro.
  - Arquitetura: monorepo com NestJS + Next.js.
  - Dados: PostgreSQL com Row-Level Security para multi-tenant.
  - Filas: Redis/BullMQ.
  - Integrações: Mercado Pago, iFood e WhatsApp.
- **Outros SaaS verticais** com a mesma base de engenharia:
  - gestão de clínicas;
  - gestão de escritórios de contabilidade;
  - barbearias;
  - entregas com motoboys.
- **Automação e IA aplicada**: atendentes de WhatsApp com LLM, SDR automatizado e coleta de leads com Google Places + IA. As ferramentas são n8n, Evolution API e Python.
